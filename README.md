## 🚀 Getting Started

Clone and run the development server locally:

```bash
git clone https://github.com/jenkij-cloud/jenkij-portfolio.git
cd jenkij-portfolio
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
